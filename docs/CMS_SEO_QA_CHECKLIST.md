# CMS SEO QA Checklist

## Conteúdo
- [ ] Título claro e alinhado à intenção de busca
- [ ] Slug curto, sem acento, sem espaços e com hífens
- [ ] Resumo objetivo
- [ ] Conteúdo cobre a dúvida principal
- [ ] H2s organizados por subtemas
- [ ] Conclusão com próximo passo

## SEO
- [ ] Palavra-chave primária preenchida
- [ ] Palavras-chave secundárias preenchidas
- [ ] Meta title preenchido e com até 60 caracteres
- [ ] Meta description entre 120 e 160 caracteres
- [ ] Status de indexação revisado
- [ ] Canonical gerado automaticamente pela página pública
- [ ] FAQ preenchido quando aplicável

## Conversão
- [ ] CTA configurado
- [ ] Serviço relacionado mencionado
- [ ] Links internos para serviços ou soluções
- [ ] Posts relacionados selecionados, quando existirem

## Imagem
- [ ] Capa configurada
- [ ] Alt text preenchido
- [ ] OG image revisada

## Publicação
- [ ] Autor preenchido
- [ ] Categoria preenchida
- [ ] Tags revisadas
- [ ] Tempo de leitura preenchido
- [ ] Preview revisado
- [ ] Status final confirmado
