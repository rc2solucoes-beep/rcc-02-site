# Checklist de Publicação de Post

## Antes de escrever
- [ ] Palavra-chave primária definida
- [ ] Intenção de busca definida
- [ ] Serviço relacionado definido
- [ ] CTA principal definido
- [ ] Links internos planejados

## Conteúdo
- [ ] H1 claro
- [ ] Introdução objetiva
- [ ] H2s cobrindo dúvidas reais
- [ ] Exemplos práticos
- [ ] Conclusão acionável
- [ ] CTA final

## SEO
- [ ] Slug curto e sem acento
- [ ] Meta title até 60 caracteres
- [ ] Meta description entre 120 e 160 caracteres
- [ ] Keyword primária preenchida
- [ ] Keywords secundárias preenchidas
- [ ] FAQ com pelo menos 3 perguntas (para guias/tutoriais)
- [ ] Posts relacionados configurados

## Publicação
- [ ] Imagem de capa adicionada
- [ ] Alt text preenchido (`cover_url_alt`)
- [ ] Autor preenchido
- [ ] Categoria preenchida
- [ ] Tempo de leitura preenchido
- [ ] Status correto
- [ ] Preview revisado
