# Search Console Monitoring — RC2 Soluções

## 1. Validar propriedade
- Preferência: validação por DNS no domínio principal.
- Alternativa: tag HTML no `<head>`.

## 2. Enviar sitemap
- Enviar `https://rc2solucoes.com.br/sitemap.xml`.
- Confirmar leitura sem erro.

## 3. Verificar indexação
- Conferir páginas principais: home, serviços, soluções, blog e contato.
- Usar inspeção de URL para páginas novas/relevantes.

## 4. Analisar consultas
- Comparar períodos (7, 28 e 90 dias).
- Identificar crescimento, queda e novas consultas.

## 5. Identificar páginas com baixa CTR
- Filtrar por páginas com muitas impressões e CTR abaixo da média.
- Revisar title/meta dessas páginas.

## 6. Identificar oportunidades de conteúdo
- Consultas com impressões altas e baixa posição.
- Consultas novas com tendência de crescimento.

## 7. Revisar páginas com posição média 8–20
- Priorizar atualizações on-page para ganhar primeira página.
- Reforçar interlinking interno dessas URLs.

## 8. Monitorar Core Web Vitals
- Verificar status em mobile e desktop.
- Priorizar URLs com maior impacto comercial.

## 9. Revisar páginas excluídas
- Separar exclusões esperadas e inesperadas.
- Corrigir apenas exclusões indevidas.

## 10. Solicitar indexação após deploys importantes
- Após mudanças relevantes de SEO, usar inspeção de URL para páginas-chave.
