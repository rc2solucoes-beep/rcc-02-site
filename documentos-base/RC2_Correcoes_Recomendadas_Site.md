# 6. Criar página `/solucoes/agenda-confirmada`

## Objetivo

Explicar a solução sem transformá-la em uma marca independente.

## Estrutura recomendada

### Hero

**Sua clínica ainda confirma agenda manualmente pelo WhatsApp?**

Automatize lembretes, confirmações e avisos usando Google Agenda ou o sistema de gestão da clínica.

**CTA:**  
**Quero automatizar minha agenda**

### Problema

- mensagens enviadas manualmente;
- recepção repetindo tarefas;
- pacientes esquecendo horários;
- cancelamentos em cima da hora;
- dificuldade para acompanhar confirmações;
- horários vagos.

### Como funciona

```text
AGENDA
↓
AUTOMAÇÃO
↓
WHATSAPP
↓
CONFIRMAÇÃO / CANCELAMENTO
↓
ATUALIZAÇÃO / ALERTA
```

### Versões

- Agenda Confirmada Start
- Agenda Confirmada Plus
- Agenda Confirmada
- Agenda Confirmada Pro

### O que não faz

- atendimento médico;
- orientação clínica;
- prontuário;
- diagnóstico;
- interpretação de exames;
- gestão completa da clínica.

### CTA final

**Agendar uma Sessão de Compatibilidade**

**Gratuita**

20–30 minutos.

- entender problema;
- verificar fit;
- identificar próximo passo.

Não inclui:

- arquitetura completa;
- roadmap;
- documentação;
- desenho detalhado.

# 21. Canonical e redirects

Para cada URL consolidada:

- configurar 301;
- atualizar links internos;
- atualizar sitemap;
- revisar canonical;
- não deixar páginas duplicadas indexáveis;
- evitar cadeia de redirects;
- testar status HTTP.

Preferir:

```text
A → C
```

em vez de:

```text
A → B → C
```
