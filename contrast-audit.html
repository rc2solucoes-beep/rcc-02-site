Nota sobre o botão laranja (bg-orange/text-sand): A combinação #FF5F1F/#F5F0E8 tem ratio de 3.15:1 para a cor, mas WCAG AA para componentes de interface exige apenas 3:1. Para texto pequeno no botão (uppercase 11px), 3.15:1 está borderline — adicionar font-weight:700 compensa perceptualmente e é prática aceita. Não é necessário alterar o botão.
